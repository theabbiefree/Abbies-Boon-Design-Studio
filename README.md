# abbies® Boon Design Studio

**A free, offline, open source generative art studio. One HTML file. No install. No account. No limits.**

Place elements. Resize them. Rotate them. Stamp them. Build something that rocks the world.

---

## What It Is

abbies® Boon Design Studio is a canvas-based creative tool where you are the designer. It gives you a set of generative art engines — kaleidoscopes, camouflage blobs, botanical flow fields, sacred geometry, ikat patterns, reaction-diffusion textures, and classic geometry — and lets you place them on a canvas one deliberate stamp at a time.

Nothing happens until you decide it happens.

---

## How It Works

1. **Choose an element** from the sidebar — geometry or generator
2. **Click the canvas** — it lands where you click with handles around it
3. **Drag to move** it anywhere
4. **Drag a corner** to resize it
5. **Drag the cyan ↻ handle** to rotate it freely
6. **Adjust controls** — palette, color, opacity, blend mode, seed — all update live
7. **Stamp It** — baked into the canvas permanently
8. **Repeat** — build your composition one element at a time
9. **Export PNG** or **Tileable PNG** when you're done

## Features

- 8 named color palettes — Abbies, Original, Nightfall, Sunset, Earth, Chrome, Military, Urban
- Per-element color override
- Opacity, rotation, size, seed, and blend mode controls
- ↩ Undo last stamp
- ⬛ Flatten canvas and keep building
- Export PNG (single) or Tileable PNG (2×2 seamless)
- Canvas sizes — 800², 1080², 1080×1350, 2048²
- Seeded RNG — every element is reproducible
- Works 100% offline — no internet required after load
- Single HTML file — open in any browser, no install
